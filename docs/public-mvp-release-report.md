## 構成と公開範囲

- `functions/api/[[path]].js` は `lib/public-api.mjs` の読み取り専用ハンドラーのみを利用。
- `GET /api/catalog` はID・年度・番号・分野の目録98件を返す。問題文・選択肢・正答・解説は一括返却しない。
- `GET /api/questions/:id` は単問の問題文・4選択肢を返す。
- `GET /api/questions/:id/solution` は単問の正答・解説を返す。画面は通常回答の確定時、または模試の提出時に取得する。
- 模試開始時は出題に必要な98問を単問APIから取得する。提出時の解説取得は最大6件ずつの並列要求に制限。
- 公開APIにはINSERT・UPDATE・DELETEの経路がない。POST/PUT/PATCH/DELETEは405。管理・旧認証・個人履歴APIは公開しない。
- 原本の参照情報・OCR・確認者情報は公開レスポンスへ含めない。
- `public/learning.mjs` が回答・復習判定・日別進捗・模試をブラウザ内で処理し、`ipas-learning-v1` キーに保存する。
- 既存の問題画面・成績画面・復習・模試の画面構成を再利用した。保存に失敗した場合はエラー表示し、成功扱いにしない。

学習用公開は今回の明示的な公開指示に基づくコード側の対象条件であり、人による内容承認とは分離している。
98問のDB上の `status=needs_review`、`explanation_status=needs_review`、確認者・確認日時NULLは変更していない。画面にも人による最終内容承認が未実施である旨を表示している。
将来内容承認を行う場合は、この学習用対象条件も見直す必要がある。

匿名の学習アプリなので単問の解説APIも公開される。画面上では回答前に正答を表示しないが、利用者がAPIを直接呼べば参照できる。本人確認・不正防止を伴う試験サービスではなく、個人の学習用模試として採点する。
