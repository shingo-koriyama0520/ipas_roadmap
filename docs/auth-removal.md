# 旧認証版の整理（2026-11-12）

旧認証API `lib/api.mjs` と専用テスト `tests/app.test.mjs`、旧認証版の利用手順・本番認証準備資料2件を削除した。
`lib/domain.mjs` はデータ取込・品質検査に必要な `publishable()` のみ残した。
承認判定テストは `tests/domain.test.mjs` へ移し、MVPデータ選別テストは維持した。
開発サーバーの未使用認証設定と構文チェックの削除済みファイル参照を除去した。

DBスキーマ、既存ローカルDB、本番D1、ブラウザ履歴、過去の作業ログ・バックアップは変更していない。
既存マイグレーションには旧認証版のテーブル定義が残るが、公開APIはquestionsをSELECTするだけである。
過去のリリース・品質報告に登場する削除済みファイル名は当時の記録であり、現行の利用手順ではない。
