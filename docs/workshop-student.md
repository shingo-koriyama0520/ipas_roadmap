# ITパスポート勉強会：ローカル版の使い方

このセットには、アプリのソースコードと2024～2026年度の問題300問が入っています。
問題とAI生成解説は人による確認待ちです。勉強会で内容を検討・修正する教材として使います。

## 1. 初回の準備（Windows）

1. Node.js 22.13以上をインストールします。公式配布元： https://nodejs.org/
2. 配布されたZIPを右クリックし、「すべて展開」を選びます。
3. 展開した `it-passport-workshop` フォルダーを、デスクトップなど自分で書き込める場所に置きます。
4. 中にある `起動.cmd` をダブルクリックします。
5. `Local preview: http://127.0.0.1:8790` と表示されたら、ブラウザでそのURLを開きます。

ZIPの中から直接起動せず、必ず展開してください。Node.jsの準備後は、通常の起動に
インターネット接続・Git・Cloudflareアカウント・npm installは必要ありません。
起動中は黒い画面を開いたままにします。終了は黒い画面で `Ctrl+C` を押します。
次回も同じ `起動.cmd` を使います。

初回起動時に自分専用のDBを作成し、300問を登録します。次回から同じ問題は重複登録しません。

## 2. 動作確認

- 「学習」で問題文と選択肢が表示されること。
- 回答すると正誤と解説が表示されること。
- 「模擬試験」で100問の模試を始められること。
- ページを再読み込みしても回答履歴が残ること。

## 3. APIとDBを見てみる

ブラウザで `http://127.0.0.1:8790/api/catalog` を開くと、問題一覧のJSONが表示されます。
`count` が `300` なら、DBからAPIを通じて300問の情報を取得できています。

1問の問題： `http://127.0.0.1:8790/api/questions/2024-001`

正解と解説： `http://127.0.0.1:8790/api/questions/2024-001/solution`

| 場所 | 内容 |
|---|---|
| `public/` | ブラウザに表示する画面とJavaScript |
| `lib/public-api.mjs` | APIの処理とSQL |
| `scripts/dev.mjs` | 自分のPCで動くWebサーバー |
| `migrations/0001_init.sql` | DBのテーブル定義 |
| `workshop/questions.json` | 問題・選択肢・正解・解説の入力データ |
| `.local/workshop/app.sqlite` | 初回起動で作られる自分専用のSQLite DB |

この配布版は `--workshop` モードで動き、2021～2026年度・各100問までを扱えます。
公開版との比較は `docs/architecture.md` を参照してください。

回答履歴・進捗・模試結果はDBではなく、ブラウザのlocalStorageに保存されます。
ブラウザのデータを消すと履歴は失われます。各受講生のデータは他のPCへ送信・同期されません。

## 4. AIで問題を修正・追加する演習

1. サーバーを終了します。
2. `workshop/questions.json` をコピーしてバックアップします。
3. AIを使って問題文・4選択肢・正解・解説を整え、元資料などと照合します。
4. 既存の形式に合わせてJSONを編集します。正解番号は0～3で、ア～エに対応します。
5. フォルダーでターミナルを開き、`npm run db:validate` を実行します。
6. `rejected` が0であることを確認します。これは形式検証であり、内容の正確性の判定ではありません。
7. 既存の問題を修正した場合は、`.local/workshop/app.sqlite` を別名にして退避します。
8. 再度 `起動.cmd` を実行すると、修正したJSONからDBを作成します。

追加だけなら再起動時に追加登録されます。同じIDで内容が異なると、上書きを防ぐため起動を停止します。
問題を削除したときも、JSONからDBを作り直すため手順7を行います。
問題を変えた後の古い回答・実施中模試は自動で整理されません。必要に応じてブラウザの
開発者ツールから、このアクセス先のlocalStorageキー `ipas-learning-v1` を削除します。
この操作で、このアプリの学習履歴は失われます。

## 困ったとき

`環境チェック.cmd` で診断し、`起動ログ.cmd` でログを保存しながら起動できます。
結果は `.local/logs` に保存されます。詳しい対処は、配布ZIP内の
`教材/ローカル環境_起動トラブル対処手順.md` を参照してください。

| 症状 | 確認すること |
|---|---|
| Node.jsが必要と表示される | Node.jsをインストールし、起動ファイルを開き直す |
| ポートが使用中と表示される | すでに開いているサーバーを終了する |
| ページが開かない | 黒い画面のエラーを確認し、`127.0.0.1:8790` を使う。`localhost` は使わない |
| データの衝突で起動しない | サーバーを止め、DBを退避してから再起動する |
| SQLiteのExperimentalWarningが出る | 警告の後にLocal previewが出ていれば起動しています |

## 勉強会のゴール

1. 画面からAPIへリクエストを送り、JSONで応答が返る仕組みを理解する。
2. 問題がDBに保存され、SQLで取得される仕組みを理解する。
3. AIで内容を確認・修正しながら、300～600問の教材を完成させる。
