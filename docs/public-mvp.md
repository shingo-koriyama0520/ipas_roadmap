# Ipasロードマップ：公開MVP

公開先: https://ipas-roadmap.pages.dev/

ログイン不要で2026年度98問を学習する。回答・14日分の進捗・模試結果はブラウザのlocalStorageに保存する。ブラウザのデータ削除で履歴は失われ、他の端末とは同期しない。

## 公開構成

- Cloudflare Pages: `ipas-roadmap`、本番ブランチ`main`、静的配信ディレクトリ`public`。
- D1: `it-passport`、バインディング`DB`。問題の再投入やマイグレーション実行をビルド手順に含めない。
- Functionsの入口は`functions/api/[[path]].js`。本番は`lib/public-api.mjs`の読み取り専用APIだけを利用する。
- `lib/api.mjs`は旧認証版のコードであり、公開Functionsからは参照しない。旧管理・認証・履歴保存APIは公開しない。
- `GET /api/catalog`は問題目録のみ。問題と解説は単問のGETで取得し、書き込みメソッドは405で拒否する。
- 問9・29は対象外。学習用の公開対象条件と人による内容承認は別管理で、DBの未承認状態を維持する。

## 開発と確認

Node.js 22.13以上を使用する。

```powershell
npm ci
npm test
npm run check
npm run format:check
npm start
```

ローカルSQLiteに問題がなければ問題一覧は空になる。公開リポジトリに問題データは含めない。
手元に修復済みJSONと品質判定JSONがある場合のみ、`npm run preview:mvp`で独立したローカルDBへ98問を読み込める。入力は`data/repair/2026/questions-repaired.json`と`quality-decisions.json`。
ローカルでの投入は本番D1を変更しない。

`tests/public.test.mjs`は合成問題のみを使い、公開範囲・書き込み拒否・14学習単位・模試・ブラウザ保存を検証する。
`.local/`の実問題を使った検証スクリプト、画面画像、DB、ログはコミットしない。検証に必要な汎用ロジックはソースと合成テストで再現する。

## Git同期時の確認

mainへのpushで既存Git連携の本番デプロイを実行する。デプロイ元コミット、配信中の静的コード、問題目録98件、学習・保存・模試、管理APIの404と書き込みの405を確認する。
D1は読み取り確認だけを行い、問題数・除外番号・承認状態・既存テーブルが変化していないことを確認する。
問題文・正答・解説・PDF・CSV・生成SQL・個人情報・認証情報はGitへ追加しない。`.gitignore`に加え、ステージされた差分を毎回確認する。

今回の同期対象は公開MVPとそのローカル起動に必要な依存、設定、合成テスト、本書のみ。以前の修復・内容レビュー資料や、旧認証版の未公開変更は対象外としてローカルに保持する。

過去コミットには問題PDFやデータファイルの履歴が残っている。現行ツリーから除外しても履歴は消えない。今回の同期では再追加も履歴書き換えも行わない。履歴の除去は影響範囲を確認した別作業とする。
